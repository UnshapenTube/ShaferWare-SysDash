# Security

## Reporting a problem

If you find a security problem in ShaferWare SysDash (for example, something that could let another program
or user abuse its administrator rights), please report it privately instead of opening a public issue:

- Use **Security > Report a vulnerability** on this repository, or
- use the contact form at https://shaferware.com/contact/.

Include the SysDash version, your Windows version and the steps to reproduce it.

## Before you post anything

Bug reports and logs are public. Do not post personal information: names, email addresses, IP addresses,
computer or user names, or file paths that contain your Windows user name. `sysdash.log` normally contains
only hardware names and errors, but read it before you paste it.

## Supported versions

Only the latest release receives fixes.
